# NeuroLab

PWA de treinamento cognitivo, funções executivas e raciocínio lógico (sem alegações médicas/clínicas), com 6 domínios cognitivos, 12 minigames com progressão infinita por fases (Stage Engine), Dual-Theme (**Minimalista** e **Gamificado**) e back-end local via Docker Compose compatível com Supabase.
